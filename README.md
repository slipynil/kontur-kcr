# Сервис обзвона клиентов (КЦР)

Система для работы операторов и администраторов с реестром клиентов и процессом обзвона: поиск клиента по коду КЦР или ИНН, карточка и история клиента, загрузка срезов реестра из Excel, формирование списков на обзвон и фиксация звонков. В системе планируется AI-ассистент, который помогает оператору и выполняет операторские сценарии через чат.

## Желаемые метрики от заказчика

| # | Метрика | Цель |
|---|---------|------|
| 1 | Время, чтобы узнать текущее состояние и историю клиента | до 1 минуты, 100% полнота информации |
| 2 | Время администратора на обработку нового среза и список на обзвон | 5–7 минут |
| 3 | Доля пропущенных повторных контактов | 0% |

## Ограничения от заказчика

- никаких интеграций с системами Контура;
- обмен данными через Excel;
- только тестовые данные;
- архитектура должна позволить позже заменить импорт из Excel на API.

## Пользователи и сценарии

**Оператор:**

1. Войти в систему
2. Найти клиента по коду КЦР или ИНН
3. Работать с общей таблицей клиентов
4. Открыть карточку клиента
5. Открыть список «Сегодня нужно»
6. Взять клиента в работу
7. Освободить клиента
8. Зафиксировать звонок

**Администратор:**

1. Войти в систему
2. Загрузить в реестр клиентов и срезы из Excel
3. Увидеть динамику после загрузки
4. Найти клиента по коду КЦР или ИНН
5. Работать с общей таблицей клиентов
6. Открыть карточку клиента
7. Сформировать список на обзвон
8. Снять клиента с оператора
9. Управлять пользователями и ролями

## Архитектура

Система делится на микросервисы по предметным областям ([ADR-0001](docs/adr/0001-split-system-into-microservices-by-domain.md), статус: *Proposed*). Так снимается главная проблема прежней системы, распределённого монолита с центральным ядром, через которое шли все запросы. Каждый сервис владеет своими данными и своей зоной ответственности, а команда может развивать сервисы независимо на своём стеке (Go, Python).

Схема контейнеров: [C4 L2](docs/c4-l2-container-diagram.html).

### Сервисы

| Сервис | Отвечает за | Стек | Хранилище |
|--------|-------------|------|-----------|
| **Gateway / Identity** | Аутентификация и авторизация, пользователи и роли, маршрутизация запросов к сервисам. Намеренно тонкий: без бизнес-логики | Go | Identity DB (PostgreSQL) |
| **Import Service** (Import API + Import Worker) | Загрузка реестра клиентов и срезов из Excel, асинхронно через очередь. Единственное место, которое меняется при замене Excel на API | Python | — |
| **Clients Service** | Реестр клиентов и история срезов: поиск по КЦР/ИНН, общая таблица, карточка клиента, динамика после загрузки | Python | Clients DB (PostgreSQL) |
| **Operator Work Service** | Процесс обзвона: списки на обзвон, «Сегодня нужно», взятие и освобождение клиента, снятие клиента с оператора, фиксация звонков | Python | Operator Work DB (PostgreSQL) |
| **Assistant Service** (+ MCP Server) | Чат с AI-ассистентом, не привязан к конкретной модели. MCP Server отдаёт операторские сценарии ассистенту как инструменты | Python | — |

### Инфраструктура

- **Web App:** SPA, веб-интерфейс операторов и администраторов.
- **nginx:** обратный прокси, терминирует HTTPS.
- **RabbitMQ:** очередь задач импорта.
- **PostgreSQL:** отдельная БД у каждого сервиса, который хранит данные.
- **LLM:** внешняя модель, генерирует ответы ассистента.

### Основные потоки

1. Оператор и администратор работают через Web App. Все запросы идут через nginx в Gateway / Identity: он проверяет токен и роль и направляет запрос в нужный сервис.
2. Администратор загружает Excel в Import API. Import API кладёт задачу в RabbitMQ и сразу отвечает. Import Worker забирает задачу, разбирает файл и загружает клиентов и срезы в Clients Service.
3. Clients Service хранит реестр в своей БД и отвечает на поиск по КЦР/ИНН, отдаёт карточку и динамику.
4. Operator Work Service ведёт процесс обзвона в своей БД. Данные клиента он запрашивает у Clients Service.
5. Пользователь пишет в чат: Assistant Service отправляет промпт во внешнюю LLM, а действия выполняет через MCP Server, который вызывает только Operator Work Service.

|--------|----------|
