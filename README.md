# Контур КЦР — контроль передачи оригиналов документов

Веб-сервис объединяет квартальные данные о документах и работу операторов. Ключ клиента — код КЦР; одному ИНН могут соответствовать несколько кодов.

## Текущая стадия

В репозитории находятся требования, архитектура, API-контракты и DDL. Начата реализация [Clients Service](services/clients/README.md): каркас FastAPI, health endpoints, миграции Clients DB и локальное применение нормализованных пакетов с историей, наследованием и идемпотентностью. Изменяющий HTTP-маршрут по умолчанию выключен до согласования авторизации (ADR-0004). Реализованы чтение, история, фильтры, расчёты и локальные rollback/delete; все бизнес-HTTP-маршруты по умолчанию выключены до интеграции авторизации и координатора. Остальные сервисы пока не реализованы. Актуальная спецификация — [spec.md 1.8](spec.md); решения Clients зафиксированы в [ADR-0003](docs/adr/0003-clients-service-rules-and-stack.md).

## Согласованные правила

- Администратор загружает Excel и явно выбирает квартал данных. Имя листа и дата файла не назначают квартал вместо пользователя. В платформе только квартальные периоды.
- Непереданные документы сохраняются с исходным периодом и учитываются в следующих кварталах до передачи без дублирования. Два квартала непрерывной задержки и более — длительная задержка; частичная передача не обнуляет срок остатка.
- Оператор видит активный пул, самостоятельно выбирает клиента и время звонка. При отсутствии действующего ожидания любой оператор может перезакрепить клиента себе.
- На WAIT_DEADLINE до установленной оператором даты сохраняются ответственный и этап, даже при новом квартальном срезе. По наступлении срока при остатке клиент доступен для обзвона; новый квартал сам по себе защиту не снимает.
- Пустые поля нового среза наследуются из предыдущих данных. Клиент получает метку «Проверить информацию» с перечнем полей; явные ноль и false не подменяются.
- Администратор отменяет последний пакет или вручную удаляет выбранные данные. При полном удалении клиента очищается его работа; при квартальном удалении сохраняются остальные кварталы и общая история.
- ИИ использует облачный API стороннего провайдера. Конкретный набор функций обсуждается отдельно; прежнее требование локальной модели отменено.

UC-08 (очередь дня), UC-10 (освобождение) и UC-11 (административное снятие) исключены по комментариям заказчика. Сроки и договорённости остаются в карточке, автоматическая очередь дня не вводится.

## Архитектура

Gateway/Identity — Go; Import, Clients, Operator Work и Assistant — Python. У владельцев данных свои PostgreSQL БД; импорт обрабатывается через RabbitMQ. Физические FK существуют только внутри одной БД. LLM — облачный внешний API; MCP и конкретные инструменты ИИ остаются предложениями до согласования функций.

## Уточнения Clients Service от 07.11.2026

ADR-0003 фиксирует динамику выбранного исходного квартала, категории FIRST_TIME/REPEATED, исправления одной даты, автоматическое снятие предупреждений и сохранение других кварталов/общей истории при квартальном удалении. Clients владеет только своей БД; стек FastAPI, SQLAlchemy, Alembic, PostgreSQL, pytest. Техническая интеграция с Gateway ещё согласуется.

Подробный план: [docs/clients-service-plan.md](docs/clients-service-plan.md).

## Динамика и чтение от 07.11.2026

Динамика сравнивает актуальные остатки двух разных исходных кварталов: выбранного и предшествующего ему. По умолчанию используются текущий календарный квартал Europe/Moscow и предыдущий. Если одного периода нет, динамика не показывается; отсутствие не считается нулём. Текущий ноль при известной паре — «Все переданы», меньше прошлого — «Уменьшается», больше — «Растёт», равен — «Без изменений». Это сравнение разных комплектов документов. В ответе видны оба квартала и оба остатка; суммарный остаток по всем исходным кварталам выводится отдельно.

ADR-0005 заменяет прежнее правило сравнения срезов внутри одного квартала. История этих срезов сохраняется. Длительность рассчитывается по загруженным наблюдениям: строки кварталов одного пакета на одну дату считаются одним наблюдением клиента; календарь не увеличивает длительность автоматически.

## Откат и удаление от 07.11.2026

Откат последнего пакета восстанавливает состояние затронутых им клиентов до импорта, включая данные, вручную удалённые после этого импорта. Например, если пакет обновил Q1 и Q2, а затем администратор удалил Q1, откат восстанавливает прежние Q1 и Q2. Клиенты, которых пакет не затрагивал, не восстанавливаются. Удаление до применения пакета является частью его исходного состояния и не отменяется.

ADR-0006 фиксирует локальную реализацию Clients. Протокол координатора: [docs/clients-recovery-protocol.md](docs/clients-recovery-protocol.md). Закрытый undo поддерживает восстановление; HTTP восстановления/удаления по умолчанию выключен до согласования авторизации и глобального координатора.

## Числовые фильтры и подготовка интеграции от 07.11.2026

Числовые фильтры количества и процента непереданных документов применяются только к выбранному исходному кварталу, а не к сумме всех кварталов. Если квартал не выбран, используется текущий календарный квартал по Москве. Диапазоны включают обе границы; процент вычисляется как количество непереданных / всего документов выбранного квартала * 100 без округления при отборе. При отсутствии квартала числовая выборка исключает клиента. При нулевом общем количестве процент не определён; процентный фильтр такую запись исключает. Общий остаток всех исходных периодов показывается отдельно.

ADR-0007 фиксирует реализацию. quarter_summary показывает выбранный период; схема БД не меняется. Авторизация токенами подготовлена только как предложение для обсуждения с разработчиком Gateway. GitHub Actions подготовлен для тестов и контейнера, но ещё не запущен.
