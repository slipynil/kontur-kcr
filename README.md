# Контур КЦР — контроль передачи оригиналов документов

Веб-сервис объединяет квартальные данные о документах и работу операторов. Ключ клиента — код КЦР; одному ИНН могут соответствовать несколько кодов.

## Текущая стадия

В репозитории находятся требования, архитектура, API-контракты и DDL. Начата реализация [Clients Service](services/clients/README.md): каркас FastAPI, health endpoints, начальная миграция Clients DB и тесты. Бизнес-маршруты и остальные сервисы пока не реализованы. Актуальная спецификация — [spec.md 1.5](spec.md); решения Clients зафиксированы в [ADR-0003](docs/adr/0003-clients-service-rules-and-stack.md).

## Согласованные правила

- Администратор загружает Excel и явно выбирает квартал данных. Имя листа и дата файла не назначают квартал вместо пользователя. В платформе только квартальные периоды.
- Непереданные документы сохраняются с исходным периодом и учитываются в следующих кварталах до передачи без дублирования. Два квартала непрерывной задержки и более — длительная задержка; частичная передача не обнуляет срок остатка.
- Оператор видит активный пул, самостоятельно выбирает клиента и время звонка. При отсутствии действующего ожидания любой оператор может перезакрепить клиента себе.
- На WAIT_DEADLINE до установленной оператором даты сохраняются ответственный и этап, даже при новом квартальном срезе. По наступлении срока при остатке клиент доступен для обзвона; новый квартал сам по себе защиту не снимает.
- Пустые поля нового среза наследуются из предыдущих данных. Клиент получает метку «Проверить информацию» с перечнем полей; явные ноль и false не подменяются.
- Администратор отменяет последний пакет или вручную удаляет выбранные данные. При полном удалении клиента очищается его работа; при квартальном удалении сохраняются остальные кварталы и общая история.
- ИИ использует облачный API стороннего провайдера. Конкретный набор функций обсуждается отдельно; прежнее требование локальной модели отменено.

UC-08 (очередь дня), UC-10 (освобождение) и UC-11 (административное снятие) исключены по комментариям заказчика. Сроки и договорённости остаются в карточке, автоматическая очередь дня не вводится.

## Архитектура

Gateway/Identity — Go; Import, Clients, Operator Work и Assistant — Python. У владельцев данных свои PostgreSQL БД; импорт обрабатывается через RabbitMQ. Физические FK существуют только внутри одной БД. LLM — облачный внешний API; MCP и конкретные инструменты ИИ остаются предложениями до согласования функций.

## Отложенные вопросы

Источник признака «Новичок» будет обсуждён с заказчиком. Набор функций ИИ, детализация дополнительных возможностей и некоторые правила категорий/закрытия ещё не утверждены — см. spec.md §7.

## Уточнения Clients Service от 07.11.2026

ADR-0003 фиксирует динамику выбранного исходного квартала, категории FIRST_TIME/REPEATED, исправления одной даты, автоматическое снятие предупреждений и сохранение других кварталов/общей истории при квартальном удалении. Clients владеет только своей БД; стек FastAPI, SQLAlchemy, Alembic, PostgreSQL, pytest. Техническая интеграция с Gateway ещё согласуется.
