# Import API и Import Worker

Из этого каталога запустите `docker compose up --build -d`. Compose поднимает Import DB и RabbitMQ, выполняет миграции и запускает два процесса.

| Процесс | Точка входа |
|---|---|
| Import API | `uvicorn import_worker.api:create_app --factory --host 0.0.0.0` |
| Import Worker | `python -m import_worker.consumer` |

API доступен на `http://import-api:8000` внутри сети Compose. Gateway проверяет права администратора и передаёт `X-User-Id` при загрузке. Для запуска вне Compose установите Python 3.14 и Poetry 2.5.1, выберите интерпретатор командой `poetry env use 3.14` и выполните `poetry sync`. Установите `IMPORT_DATABASE_URL`, `IMPORT_AMQP_URL` и `IMPORT_UPLOAD_DIR`, примените `poetry run alembic upgrade head` и запустите обе команды через `poetry run`. Для стенда нужны свои учётные данные PostgreSQL и RabbitMQ.

Для изолированной разработки задайте `IMPORT_LOCAL_CLIENTS_URL` как базовый URL Clients Service с включённым маршрутом `/internal/v1/import/apply`. В отдельном Compose-проекте Clients должен быть доступен из сети Worker. Без этой настройки готовое задание остаётся доступным для повтора. При локальном успехе Clients отчёт содержит `clients_applied_at`, а статус остаётся `PROCESSING` до согласованного обновления Operator Work. Если все строки уже были приняты в предыдущих пакетах, повтор завершается как `COMPLETED` без изменений. Отклонённый целиком пакет получает `FAILED`. В отчёте номер строки 0 обозначает сообщение о книге или листе.

Исходный квартал для `SNAPSHOT` задаётся столбцом `Исходный квартал` или `quarter` в формате `YYYY_QN`. В исторических листах без этого столбца используется выбранный квартал. Для выгрузки с остатками нескольких исходных периодов указывайте период каждой строки. Пустое значение в этом столбце и исходный квартал позже выбранного считаются ошибками. Годовые и составные листы и листы с явно другим кварталом пропускаются. Импорт поддерживает исторические позиции столбцов и перестановку столбцов с распознаваемыми заголовками. Размер загружаемого файла по умолчанию ограничен 32 МиБ через `IMPORT_MAX_UPLOAD_BYTES`.

Ошибки доступны в JSON-отчёте и отдельной книге по внутреннему маршруту `GET /internal/v1/imports/{batch_id}/errors.xlsx`. Книга содержит лист, физический номер строки, код КЦР и причину. Публичный маршрут для скачивания требует подключения в Gateway.

В RabbitMQ передаётся JSON с `batch_id`. В случае сбоя публикация повторяется по журналу Import DB, а запрос к Clients повторяется с сохранённым содержимым и тем же UUID. Пока результат начатого HTTP-вызова неизвестен, Worker восстанавливает его перед применением следующего пакета. Запрос в Import DB и XLSX в закрытом томе удаляются после завершения локальной обработки. API также удаляет XLSX при ошибке создания записи до начала фиксации транзакции. При аварийном завершении процесса или неизвестном результате фиксации файл может остаться в томе.

Откат отсутствующего пакета возвращает `404`, заведомо неподходящего — `409 IMPORT_NOT_LATEST`. Для кандидата возвращается `503 IMPORT_ROLLBACK_UNAVAILABLE` до согласования глобального порядка, очистки Operator Work и возобновления частично выполненной операции. Undo с данными Clients фиксируется владельцем в его транзакции.

## Проверки

```sh
poetry check --lock
poetry sync
poetry run ruff check .
poetry run ruff format --check .
poetry run python -m pytest --cov=import_worker
docker compose -p kontur-import-test -f compose.yaml -f compose.test.yaml run --build --rm import-tests
```

Последняя команда запускает интеграционные тесты на отдельном стенде с PostgreSQL и RabbitMQ. Clients Service в этих тестах заменён HTTP-имитацией. Для запуска проверок с уже поднятыми тестовыми службами задайте `IMPORT_TEST_DATABASE_URL` и `IMPORT_TEST_AMQP_URL`. Перед тестами примените миграции к пустой тестовой Import DB. Тест RabbitMQ использует ту же очередь, что и Worker, поэтому запускайте его на отдельном брокере.

`IMPORT_TEST_CLIENTS_URL` дополнительно включает проверку истории и переноса остатков через HTTP с настоящим Clients Service. Используйте отдельную тестовую Clients DB и включите маршруты применения импорта и чтения реестра.
