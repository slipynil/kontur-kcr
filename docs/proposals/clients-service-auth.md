# Авторизация внутренних вызовов Clients

Предложение для согласования с Gateway и Import. В коде пока не реализовано.

Для первого стенда предлагаются отдельные Bearer-токены. Токен Gateway даёт доступ к чтению, токен Import — к применению пакета, откату и удалению. Пользовательские права проверяет Gateway. Внутренний вызов передаёт автора из проверенного контекста в `uploaded_by` или `requested_by`.

До реализации нужно согласовать выдачу и ротацию секретов, передачу пользовательского контекста и доступ Operator Work. Текущие условия локального запуска описаны в [README Clients](../../services/clients/README.md).
