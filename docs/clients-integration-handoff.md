# Подключение Clients к соседним сервисам

Запросы, ответы и коды ошибок приведены во [внутреннем OpenAPI Clients](api/internal/clients-service.yaml).

- Gateway дополняет карточку назначением, этапом и сроком из Operator Work. Для списка нужно согласовать, как объединить клиентские и операторские фильтры до подсчёта общего числа строк и пагинации.
- Import передаёт нормализованные строки. `quarter` обозначает исходный период документов, `work_quarter` — квартал работы оператора. Коды КЦР, ИНН и КПП передаются строками, чтобы сохранить ведущие нули.
- Для удаления и отката нужен [координатор Import](clients-recovery-protocol.md). Перед подключением общего стенда Gateway и Import согласуют [авторизацию внутренних вызовов](proposals/clients-service-auth.md).
