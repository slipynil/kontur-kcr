# План завершения Operator Work Service

Дата фиксации: 09.11.2026. Обновлено 11.11.2026. Основания: [спецификация](../spec.md), [ADR-0006](adr/0006-targeted-operator-cleanup.md), [ADR-0007](adr/0007-import-worker-coordinator.md), [контракт с Import Worker](api/import-operator-work-contract.md).

Порядок обязателен. Один этап оформляется отдельной задачей. Следующий этап начинается после проверки предыдущего и согласования решений, от которых он зависит. Если этап заблокирован, фиксируется причина, а порядок не меняется. Новый объём работ добавляется только по решению пользователя.

Локальная публикация пула, назначение и перезакрепление, звонки, прошлые комментарии, обработка WAIT_DEADLINE, применение тестового среза и локальная очистка уже реализованы. Ниже остаются только незавершённые обязательные задачи.

| № | Задача | Критерий готовности | Состояние |
|---|---|---|---|
| 1 | Чтение состояния цикла для восстановления | Доверенный администратор через API получает устойчивый ID, квартал, публикацию, этап, UUID ответственного, срок и источник ожидания, в том числе для исторического и неопубликованного цикла. Чтение не меняет рабочее состояние. Контракт и тесты соответствуют ответу. | Выполнено и проверено |
| 2 | Подтверждённая привязка целей выборочной очистки | У Import Worker есть проверяемый источник связи между исходными периодами или пакетом и точными ID событий и циклов. При неоднозначности очистка останавливается. Общая история и работа по другим периодам сохраняются. | Выполнено и проверено. ADR-0008 |
| 3 | Доставка больших пакетов | Выгрузка больше 1000 клиентов применяется частями или иным согласованным способом. Исходный ID пакета сохраняется для отката, повторы не дублируют циклы, сбой посередине не даёт ложного итогового успеха. | Локальная часть выполнена и проверена на 1002 клиентах. ADR-0009 |
| 4 | Подключение и сквозная приёмка | Import Worker получает остатки из Clients, применяет срез и координирует откат. Gateway передаёт проверенные UUID и роли. На связанных сервисах проходят ручная публикация, звонок, смена квартала, возврат после ожидания, откат и повтор после сетевого сбоя. | Следующий этап. Clients предоставляет остатки для локальной проверки. В Import Worker предстоит подключить доставку срезов и координацию отката. Для Gateway остаётся подключение авторизации и маршрутов |

Претензии, санкции, письма, вложения, импорт старой истории и автоматическое закрытие при нулевом остатке не входят в этот план до отдельного согласования.
