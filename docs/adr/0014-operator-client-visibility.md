# 0014. Доступ оператора к клиентам

## Status

Accepted — согласованный план ограничения доступа оператора.

## Decision

- Оператору виден клиент со статусом `ACTIVE` в Clients и текущим опубликованным циклом в Operator Work. Правило распространяется на свободных клиентов и клиентов коллег. `WAIT_DEADLINE` ограничивает перезакрепление, `is_blocked` остаётся отдельным полем профиля.
- Gateway определяет роль из JWT. Для реестра он получает коды текущих опубликованных клиентов и передаёт их в Clients через JSON-тело внутреннего запроса. Clients применяет коды, статус и остальные фильтры до подсчёта и пагинации. Пустой список кодов даёт пустую выборку.
- Карточка, лента, история срезов и действия по коду возвращают `404` для скрытого клиента. Пул и уведомления ограничиваются тем же набором кодов. Проверка роли и владельца запроса перезакрепления сохраняется. Ошибка участника прерывает запрос.
- Администратор читает весь реестр. Квартальное чтение пула и защита по сроку ожидания продолжают действовать. Ассистент по карточке использует проверку доступа к клиенту. Общий ИИ-поиск и чат доступны администратору до согласования передачи области доступа ассистенту.

## Consequences

Изменения статуса после импорта или отката учитываются при следующем чтении. Gateway проверяет видимость на момент обработки запроса. Операции назначения и перезакрепления сохраняют собственную транзакционную проверку Operator Work. Миграции базы не требуются.
