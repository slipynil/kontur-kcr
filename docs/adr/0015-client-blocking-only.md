# 0015. Блокировка как единственный признак клиента

## Status

Accepted

## Decision

- Профиль клиента использует только `is_blocked`. Импорт берёт значение из колонки «Блокировка в сервисе». Колонка «Действует ли КЦР» больше не влияет на профиль.
- Миграция сохраняет существующее значение `is_blocked` и удаляет `status`. Бывший `INACTIVE` с `is_blocked=false` доступен оператору при наличии текущего опубликованного цикла.
- Для оператора правило ADR-0014 применяется по `is_blocked=false` и текущему опубликованному циклу. Администратор по-прежнему видит весь реестр.
- Пакеты старого формата можно завершить и повторно доставить. Значение `status` в них игнорируется при записи профиля. Откат импорта восстанавливает прежний `is_blocked`.
