# 0019. Мгновенное перезакрепление клиента

## Status

Accepted — решение пользователя по задаче #87.

## Decision

- Оператор может сразу закрепить за собой клиента текущего опубликованного цикла. Для занятого клиента он передаёт ID активного назначения, для свободного — null.
- Operator Work под блокировкой клиента проверяет версию назначения и срок ожидания, завершает прежнее назначение и сохраняет новое назначение и событие в одной транзакции.
- Новые запросы на перезакрепление и уведомления при этом действии не создаются. Успешное действие возвращает 200 с назначением. Если при успешной смене владельца ещё ожидает старый запрос, он отменяется в той же транзакции.
- История и обработка уже созданных запросов сохраняются для совместимости. Меню и диалог запросов удалены из операторского интерфейса.

## Consequences

Это решение заменяет правила создания запросов из ADR-0004. Миграция БД не требуется. Gateway продолжает использовать существующий маршрут и проверку видимости для оператора.
