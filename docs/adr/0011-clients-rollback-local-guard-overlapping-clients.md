# 0011. Локальная проверка отката Clients ограничена общими клиентами

## Status

Accepted — решение пользователя от 17.11.2026 (вариант A в обсуждении исправления e2e-сбоя отката).

## Context

Глобальную проверку «последнего применённого пакета системы» по ADR-0006 выполняет Import Worker по `import_batches`. Дополнительная локальная проверка Clients сравнивала `apply_order` со всеми активными записями `clients_import_operations` — включая применения, не затрагивающие клиентов откатываемого пакета. Из-за этого откат последнего пакета блокировался `409 IMPORT_NOT_LATEST` любым более поздним применением по другим клиентам: соседним пакетом импорта или синтетическим применением внутреннего API стендов и e2e-фикстур.

## Decision

1. Локальная проверка Clients блокирует откат только при наличии более позднего по `apply_order` активного применения, затрагивающего хотя бы одного общего клиента с откатываемым пакетом (пересечение `clients_import_undo.kcr_code`).
2. Правило публичного API не меняется: Import Worker по-прежнему разрешает откат только последнего применённого пакета системы.
3. Для пакетов без `apply_order` (до миграции ADR-0006) порядок неизвестен и остаётся глобальным: активный новый пакет даёт `IMPORT_NOT_LATEST`, несколько старых — `IMPORT_ORDER_UNKNOWN`.

## Consequences

Откат пакета больше не блокируется изменениями по не затронутым клиентам, в том числе параллельными применениями стендов. Корректность undo сохраняется: применение поверх общего клиента по-прежнему запрещает откат лежащего под ним пакета. Код и текст ошибки `409 IMPORT_NOT_LATEST` не меняются, контракты совместимы.
