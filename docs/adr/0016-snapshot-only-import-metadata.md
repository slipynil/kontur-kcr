# 0016. Квартал и дата только при загрузке среза

## Status

Accepted — уточнение пользователя от 19.11.2026.

## Context

Реестр обновляет профили клиентов. Квартал наблюдения и дата среза нужны для учёта состояния документов и квартального цикла обзвона.

## Decision

- Для `REGISTRY` администратор выбирает файл `.xlsx`. Импорт применяет профили по коду КЦР в порядке обработки пакетов. Для происхождения полей профиля из реестра сохраняется ID пакета.
- Для `SNAPSHOT` обязательны `selected_quarter` и `snapshot_date`. Это уточняет область применения пункта 2 ADR-0002. Фильтрация листов по выбранному кварталу применяется к срезу с учётом ADR-0013.
- Поля доступны в форме и отчёте только для среза. API загрузки и применения требует оба поля для `SNAPSHOT` и принимает `REGISTRY` без этих полей. В журнале Import DB у пакета реестра оба значения равны `NULL`.
- Повтор доставки того же пакета идемпотентен. Дедупликация наблюдений между пакетами применяется к срезам. Новая загрузка реестра может вернуть ранее использованное значение профиля.

## Consequences

Миграции очищают квартал и дату в старых пакетах реестра и в происхождении полей, полученных из этих пакетов. ID, результаты загрузок и данные срезов сохраняются. Старые метаданные реестра удаляются без возможности восстановления миграцией вниз.

Перед обновлением остановить приём загрузок и дать старому Worker завершить начатые пакеты реестра. Если результат отправки реестра в Clients ещё неизвестен, миграция Import DB останавливается до сверки старого запроса. Обновлённые Import API и Worker используют новый контракт Clients Service.
