# 0005. Сохранение звонка при смене ответственного

## Status

Accepted — уточнение пользователя от 09.11.2026.

## Decision

Оператор сохраняет результат звонка с идентификатором назначения, под которым была открыта форма. Сервис проверяет, что назначение принадлежало этому оператору и относится к клиенту в текущем квартальном цикле.

Если ответственный сменился, звонок сохраняется в истории с авторством прежнего оператора. Этап и срок ожидания может изменить только оператор с актуальным назначением. Устаревшая форма сохраняет звонок без применения срока, даже если оператора позже назначили повторно.

При действующем назначении результат звонка и запрошенный переход в WAIT_DEADLINE сохраняются атомарно. Срок договорённости и срок ожидания хранятся отдельно. Операция повторяется с тем же ID для защиты от дублей. Исторический квартальный цикл остаётся доступным только для чтения.
