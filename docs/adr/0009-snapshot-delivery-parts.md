# 0009. Подтверждение частей большого пакета

## Status

Accepted — решение пользователя от 11.11.2026.

## Decision

Import Worker делит нормализованный пакет на части до 1000 клиентов. У всех частей общий исходный batch_id и квартал. У каждой есть свой delivery_id, номер и общее количество частей. Один клиент входит только в одну часть. Operator Work применяет и подтверждает каждую часть своей транзакцией. Происхождение цикла указывает на исходный batch_id для отката.

Import Worker сохраняет подтверждения и завершает весь пакет после подтверждения всех частей. Повтор отправляет ту же часть с неизменными полями. Изменённое тело, повтор номера с другим ID, пересечение клиентов и смешение способов доставки под одним batch_id считаются конфликтом. Одноразовая доставка пакетов до 1000 клиентов сохраняется.
