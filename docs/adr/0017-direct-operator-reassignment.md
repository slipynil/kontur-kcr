# 0017. Немедленное перезакрепление клиента

## Статус

Принято по уточнению заказчика от 21.11.2026. Заменяет ADR-0004 и уточняет правила WAIT_DEADLINE в ADR-0002 и ADR-0014.

## Решение

- Оператор может сразу взять на себя клиента из текущего опубликованного цикла на любом этапе. В карточке и реестре виден текущий ответственный. Доступ к клиентам определяется действующими правилами видимости.
- Operator Work в одной транзакции проверяет ожидаемое назначение, завершает предыдущую запись, создаёт новую и пишет событие в ленту. Повтор с тем же ID возвращает сохранённый результат. При параллельной смене назначения оператор обновляет карточку перед повторным действием.
- При перезакреплении действующее ожидание сохраняет этап, дату и источник. Если оператор явно берёт клиента после истечения срока, цикл переходит в «В работе». Автоматический возврат в пул по сроку по-прежнему требует подтверждённого положительного остатка.
- Звонок из уже открытой формы сохраняется за прежним оператором по ADR-0005. Его срок ожидания применяется только при совпадении с актуальным назначением.
- При миграции удаляются записи старых запросов. Ожидающие запросы не вызывают смену ответственного. История закреплений и лента событий сохраняются.
