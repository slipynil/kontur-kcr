# 0007. Import Worker координирует применение и откат пакетов

## Status

Accepted — решение пользователя от 09.11.2026.

## Context

Clients хранит результаты наблюдений и актуальные остатки. Operator Work хранит циклы обзвона и историю работы. Применение и откат пакета затрагивают оба хранилища. Выборочную очистку Operator Work определяет координатор по правилам ADR-0006.

## Decision

Import Worker координирует применение и откат пакетов. Он проверяет, что откатывается последний допустимый пакет, фиксирует ход операции, определяет и передаёт точные цели очистки и, когда нужно, явно задаёт состояние для восстановления. Import Worker отвечает за повторы с неизменными идентификаторами и за итоговый статус операции. Operator Work применяет изменения в своей БД и подтверждает только локальный результат.

Публикация пула остаётся отдельным действием администратора.

## Consequences

У каждого сервиса своя транзакция. Успех всего процесса публикуется после подтверждений затронутых сервисов. Возобновление после сбоя продолжает незавершённые шаги по журналу координатора. Рабочая версия [контракта Import Worker и Operator Work](../api/import-operator-work-contract.md) описывает текущий API и условия сквозного подключения.
