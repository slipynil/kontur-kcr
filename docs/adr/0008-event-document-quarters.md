# 0008. Привязка событий к исходным кварталам документов

## Status

Accepted — решение пользователя зафиксировано 11.11.2026.

## Decision

Operator Work сохраняет исходные кварталы документов явно при записи звонка или прошлого комментария. Массив document_quarters относится к документам и не заменяет work_quarter. Пустой массив означает общее событие или отсутствие доказанной привязки. Несколько исходных кварталов означают общую для них историю. Ранее записанные события остаются без доказанной привязки.

Import Worker получает привязки в ленте и передаёт точные ID по ADR-0006. При выборочной очистке сохраняются пользовательские события с пустой или множественной привязкой. При удалении исходного квартала пользовательское событие можно удалить только при единственной привязке к этому кварталу. Системная запись назначения или этапа удаляется вместе с явно выбранным циклом. Если защищённое событие находится внутри удаляемого цикла, операция возвращает конфликт до согласования другого плана. Полное удаление клиента сохраняет прежнюю семантику.

При откате пакета принадлежность наблюдений к пакету определяет Import Worker на основании данных Clients. Привязка к исходному кварталу сама по себе не является признаком происхождения от конкретного пакета.
