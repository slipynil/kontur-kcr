# 0013. Загрузка отдельного годового среза в выбранный квартал

## Status

Accepted — уточнение пользователя от 19.11.2026.

## Context

Часть исторических выгрузок представлена отдельным файлом с единственным листом за год. Поквартальной разбивки в таком файле нет. В смешанной книге годовой итог может дублировать данные отдельных квартальных листов.

## Decision

Администратор выбирает квартал при загрузке. В файле среза с единственным годовым листом значения из строк без колонки исходного периода относятся целиком к выбранному кварталу. Если колонка исходного периода есть, действуют обычные правила проверки её значений. В смешанной книге годовые и составные листы по-прежнему пропускаются.

## Consequences

Модель остаётся квартальной. Система не распределяет годовые числа между несколькими периодами. Обычные правила проверки клиентов, расчёта остатков, истории и отката применяются к выбранному кварталу. Решение уточняет пункт 2 ADR-0002 для отдельного годового файла.
