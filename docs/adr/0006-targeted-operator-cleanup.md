# 0006. Выборочная очистка Operator Work

## Status

Accepted — решения пользователя от 09.11.2026.

## Decision

При удалении исходного квартала или откате пакета координатор передаёт точные идентификаторы циклов и событий Operator Work. Исходный квартал документов не определяет квартал обзвона. Удаление цикла допускается, только если явно перечислены все его события. Общие события без цикла сохраняются. При откате удаляемый цикл должен быть создан указанным пакетом.

Если откат удаляет текущий цикл и остаётся история циклов, координатор явно указывает цикл и состояние для восстановления. Operator Work не выбирает текущий цикл по максимальному кварталу после удаления. Запись об очистке и её изменения фиксируются в одной транзакции, повтор возвращает прежний результат.
