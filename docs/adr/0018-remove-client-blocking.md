# 0018. Удаление блокировки клиента

## Статус

Принято по уточнению заказчика. Заменяет ADR-0015 и уточняет правила видимости в ADR-0014.

## Решение

- Оператору доступен клиент из реестра с текущим опубликованным циклом Operator Work. Правило применяется к поиску, карточке, истории, пулу и действиям оператора. Администратору доступен весь реестр.
- Импорт пропускает прежнюю колонку блокировки, в том числе в выгрузках старого формата. Поле `is_blocked` удаляется из контрактов и профиля клиента.

## Миграция

В Clients удаляем колонку и упоминания поля в источниках, истории и копиях для отката. В Import удаляем поле из сохранённых пакетов. Прежние значения блокировки после миграции восстановить невозможно.

Перед миграциями приостанавливаем загрузки. Старый Import Worker завершает начатые доставки с неподтверждённым результатом, сохраняя исходный хеш при повторе. Затем останавливаем старые процессы Import и применяем миграции.

Clients и Gateway обновляются вместе, поскольку меняется внутренний маршрут проверки кодов из опубликованного пула.
