# Откат и удаление: действия координатора

[ADR-0006](adr/0006-clients-rollback-and-deletion.md) описывает локальное восстановление. Запросы и коды ответов приведены во [внутреннем OpenAPI Clients](api/internal/clients-service.yaml).

Для интеграции Import и Operator Work требуется следующий порядок:

1. Координатор сохраняет административную команду и её UUID до первого вызова. При откате он проверяет глобальный последний применённый пакет, включая пакеты без принятых строк Clients, и блокирует конкурирующее применение до завершения восстановления.
2. Gateway передаёт координатору подтверждённого автора. Внутренние запросы к Clients, включая DELETE, передают его в JSON как `requested_by` вместе с `operation_id`. После таймаута координатор повторяет команду с тем же телом и ID.
3. После ответа Clients с `local_only=true` координатор выполняет очистку или восстановление в Operator Work и обновляет затронутые кэши. Для восстановления работы Operator Work нужны собственные данные восстановления.
4. Координатор сохраняет прогресс каждого участника для продолжения после сбоя. Публичный API подтверждает завершение после всех участников.

Срок хранения данных восстановления и политика повторов координатора требуют согласования.
